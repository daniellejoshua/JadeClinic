' HOW TO USE THE MODULAR NAVIGATION SYSTEM
' ==========================================

' 1. Add this import to the top of any form:
' Imports [YourProjectName] ' Replace with your actual project name if needed

' 2. In your form, ensure you have a Guna2Panel for navigation (e.g., "NavigationPanel")

' 3. In your Form_Load event, add this single line:
' NavigationModule.CreateNavigationMenu(Me, NavigationPanel, LogoControl, "CurrentPageName")

' EXAMPLE IMPLEMENTATION:
' ======================

' ROLE-BASED ACCESS:
' ==================
' The navigation automatically shows/hides menu items based on user role:
' 
' STAFF (Level 1):
'   - ?? Dashboard
'   - ?? POS / Sales
'
' MANAGER (Level 2):
'   - ?? Dashboard  
'   - ?? POS / Sales
'   - ?? Inventory
'   - ?? Sales Records
'   - ?? Staff Management  
'   - ?? Inventory Logs
'
' ADMIN (Level 3):
'   - All Manager permissions PLUS:
'   - ?? Audit Logs
'   - ?? System Settings
'
' PERMISSION CHECKING:
' ===================
' You can also check permissions in your code:
'
' If NavigationModule.HasPermission(NavigationModule.UserRole.Manager) Then
'     ' User has Manager or Admin permissions
'     EnableManagerFeatures()
' End If
'
' Dim roleText As String = NavigationModule.GetRoleDisplayText()

' - Dark Slate (#2B2F32) for navigation background  
' - Deep Charcoal (#1A1D1F) for main backgrounds
' - And all other colors from the palette

'                     |                 |     ??? Form type to open
